# Feel-pass — Spark Console UX refresh (2026-08-08)

Track: feel-pass (~15 min) · desktop 1600 + iPhone 390 PWA widths

## 5 bullets

1. Cold open: brand reads as **Spark / Console** (mark + wordmark), not a generic emoji header; Pulse hero tells the story first (“N things need you”).
2. Primary path: host gauges + feet are scannable; live pill + “updated now” make freshness obvious.
3. Break / inputs: Electricity $/kWh + Bill basis stay editable; idle wall W only for Wall estimate.
4. Loading / empty: Quick actions empty is calm; Needs you / Projects keep list rhythm.
5. Would a stranger keep this? **almost → yes** after instrument theme — denser than a consumer app but fits ops; iPhone bottom tabs are thumb-reachable with clear active state.

## States

- loading: live pill → “…” then “live”
- empty: attention all-clear / empty project rows
- error: header toast on phone / err chip on desktop
- success: hero + hosts + panels filled
